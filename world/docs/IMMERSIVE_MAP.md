# 扩大地图与画面内界面

本轮把游戏由“地图 + 页面面板”改成铺满窗口的游戏视口。对话、调查、密码、手记、物品和状态都叠加在同一游戏画面内，不需要滚动网页寻找操作区域。

## 地图

- 逻辑尺寸从 480×285 扩为 **768×480**，面积约 2.7 倍。
- 原有广场、杂货铺、舞台和离镇铁门保留，原谜题与存档坐标兼容。
- 东侧新增可走通的林间步道，南侧新增庭院环路、石井、旧碑、围栏和路灯。
- 两处可调查点提供额外的规则来源与交接线索；不是新增的通关前置条件，仍能按原路径解谜。
- 地图采用 Kenney CC0 图块，整数倍率显示；相机随玩家移动，小地图标出道路、调查点与当前位置。
- 九个可走区域由后端校验，拒绝穿越草地和场景物件，步行不扣回合、不调用模型。

## 画面内操作

- **WASD / 方向键**：沿小路连续行走。
- **E**：靠近后调查或交谈，下方出现画面内浮层。密码输入也在浮层内。
- **J**：打开或收起夜行手记。新证据取得后自动展开，原文可以反复阅读。
- **Esc**：结束输入或收起当前交互；手记打开时暂停移动。
- 对话输入不会触发 WASD 移动。走远后自动收起对应交互。
- 倒计时和异常值位于右上角；底部显示按键提示、携带物品、自动保存与观察/等待操作。
- 手机使用画面左下角的方向按钮和 E；浮层、手记、输入框均限制在当前游戏视口内。
- 全屏时仍然保留所有网页控件和操作层。

## 验证

- 后端 33 项测试通过，包含新增环路的连通性、免费步行、两处可选线索和不可穿越区域。
- 浏览器 6 项集成测试通过：原谜题完整通关、手机触控、全屏与缩放、Canvas 兼容模式、扩图探索与镜头跟随、手机浮层/密码输入/J 键。
- 浏览器实际检查游戏画布占满 1440×1000 视口；390×844 手机视口无横向或纵向网页溢出。
- 新地图仍由 `scripts/build-town-map.py` 从后端语义导出 Tiled 兼容 JSON，避免渲染与碰撞区域各写一份。
