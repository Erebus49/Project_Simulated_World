# 第一夜：谢幕后，不要回头

这版将现有广场、杂货铺、舞台改成规则怪谈解谜，没有增加场景。旧庆典版保留在 `/?legacy=1`，原存档继续存在。

## 玩法

按住 WASD 或方向键连续走动，靠近居民或调查点按 E。地图可行走范围由前后端共同校验，不能穿过房屋、水面或树木，也不能隔空调查。手机使用方向按钮和 E 按钮。

走路、观察和阅读已收集手记免费。调查操作、交谈与等待各占一回合。默认在 18 回合内离镇，可选择 12 或 24 回合。输入对话和密码时移动快捷键停用，Escape 可以结束输入。

公告栏存在被篡改的规则；旧账册给出可推导的柜号。收集实物证据，判断广播与交接操作，在钟响前离开。错误密码、回应广播、盲目播放音乐或错误交接会累计异常，第三次异常判负。操作失败会给出基于证据的反馈，可以重新判断。

线索原文、物品状态、回合与精确位置自动保存。刷新后可继续。整场谜题可以在不调用模型的情况下完成，NPC 对话用于取得、比较线索和识别误导。

## 对话加速

- 夜间版仅唤醒正在交谈的 NPC，不再每次等待四个角色。
- 走路、调查、密码和设施操作不调用模型，同步完成规则裁决。
- 夜间角色上下文只取本人简报及最近十条有关的对话、判断与经历。
- DeepSeek 请求使用 `thinking: {type: disabled}`，输出上限 320 token，台词要求简短。
- 玩家发送后立即轮询结果；本机约每 180ms、外网约每 400ms 查询一次，不等待原来 2.5 秒的刷新间隔。
- 超时或不合法回复仍只让该角色等待，不能修改谜题事实。

当前真实端点两次本机端到端对话实测 **2.08s、2.34s**；Cloudflare 网页实际发送至显示回复实测 **3.31s**。这是少量实测，不是每次响应的保证。此前庆典全角色回合耗时约 7—8 秒，比较的是不同调度方式下玩家需要等待的时间。

## 本轮验证

后端 `python -m pytest -q`：31 项全部通过。新增谜题、位置、隐私、调度和快速模型参数测试；同时保留旧庆典、分享权限、SSE 与恢复测试。TypeScript 检查与 Vite 生产构建也通过。

浏览器使用独立上下文实际按键操作：

1. WASD 走到公告栏，E 调查，读入第一份线索。
2. 到杂货铺与店主交谈，在输入框键入 `wasd`，位置保持不变。
3. 查看旧账册，根据证据打开回收柜。
4. 刷新，精确位置与三份证据保留。
5. 走到舞台完成交接，再去南门离镇。
6. 共 8 次决定，0 次异常，显示生还结局，无页面异常或横向溢出。

另通过现有 Cloudflare 链接新建 AI 夜间局，实际交谈成功，随后在 390px 手机视口长按方向按钮，角色位置变化且无横向溢出。外网入口仍不开放模型设置与完整调试。

验收脚本 `scripts/night-browser-smoke.js` 是供 Playwright `browser_run_code_unsafe` 工具加载的函数；不能直接当作 Node CLI 使用。
