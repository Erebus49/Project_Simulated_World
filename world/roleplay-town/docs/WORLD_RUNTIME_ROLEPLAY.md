# 松果镇：像素角色扮演 MVP

主入口 http://127.0.0.1:8011 。根目录运行 `npm run build`、`npm start`，或双击 `start.bat`。旧 Python 游戏的 8000 端口、存档和前端保留。

默认端口为8011，可以通过 PORT 环境变量更改。项目运行只使用本目录的源码、配置和素材。

## 玩法

- WASD / 方向键自由走动；镜头跟随。建筑、水域和树木会阻挡行走，也可以点击可行走的地面移动。移动端提供方向按钮。
- 靠近居民，会出现名字和 E 提示。按 E 打开人物对话，自由输入文字，Enter 发出、Shift+Enter 换行、Esc 结束。
- 底部行动栏可以翻日记、买咖啡、帮忙做事、停留片刻、打开菜单。买咖啡需到咖啡店，工作需到咖啡店或集市。
- J 打开日记：背景、自己此行的打算、居民的公开介绍、收到的对话记录和已经发生的事实。离开后仍可回顾对话，发送新消息需找到对方。
- 人物对话没有预写分支。可以追问、讨论、拒绝、帮忙；实际资源变化由代码结算。暂未实现签约、投资、共同经营和分支结局，这些只可作为角色讨论的话题。

## 故事与人物

《雨季前的最后一晚》：松果咖啡的租约还有三天到期，阿栗寄来一封邀请，请你回镇小聚。你离开了两年，带着40金币回来，可以自由决定自己怎样参与。

阿栗是咖啡店主，小周是店员，林岚是教师，陈默是摄影师，老何是供应商，小满是小报编辑。公开介绍可在日记里查看；各自未公开的经历、顾虑与目标只进入本人观察和提示词，不会直接出现在玩家页面。

## 模型

复制 `runtime.env.example` 为 `.env.runtime`，填写兼容 Chat Completions 的 MODEL_BASE_URL、MODEL_NAME、MODEL_API_KEY 后重启。`npm start` 自动加载此文件，环境变量仍可覆盖文件值。本机已沿用用户此前提供的 DeepSeek 配置；密钥未写进源码、网页或运行导出。

默认每位 NPC 都使用 LLM。未配置时入口不允许假装进入 AI 模式；可以显式选择 Mock 演示界面。Mock 不具备完整人物对话能力。模型请求有并发上限3、请求超时15秒、批次超时30秒和单局300次调用预算，失败时角色等待并提示，不伪造对话。

## 世界边界

这是本机单局原型。像素坐标由客户端控制，世界引擎以咖啡店、广场、集市三个区域校验可达性；目前没有把每个像素坐标纳入权威存档。普通走路不调用 LLM，进入另一区域或采取行动才推进逻辑时钟。居民的自主行动也在这些时刻发生，并非持续后台调用模型。

在模型等待期间仍可走动；交谈界面、日记和菜单打开时暂停移动。玩家行动通过统一校验和事件结算入口，LLM 不直接写入世界。NPC 的区域移动来自引擎确认的 move 动作，前端通过 A* 寻路和正面手脚动画表现连续移动；像素级行走耗时与逻辑 tick 并不等同。角色实例保持稳定，不在每次区域或网络更新时重建。场景暂为室外连续小镇，建筑室内尚未开放。

玩家 API `/api/play/state` 和 WebSocket `/ws/play` 返回自己的资源、记忆、可见事件、公开介绍；appearance 另外提供同区及相邻户外区域中可看到的角色位置与移动起讫信息，用于地图表现。跨区的可见角色不自动变成可交谈对象。NPC 的私有目标、钱款、物品与私聊仍不在玩家投影中，NPC 自身的观察边界没有扩大。`/api/play/export` 导出见闻 JSON，供阅读，不是可继续游玩的存档。

调试台 `/?debug=1` 共用当前世界，具备全知观察和干预能力。完整调试导出包含私有信息，可在调试台回放；它和玩家模式不是权限隔离的多人服务。重启会清空内存世界，需自行导出记录。

## 关键代码

- `src/ui/PixelTown.tsx`：Phaser 生命周期、DOM 地图标签、键盘与触控桥接。
- `src/ui/game/TownScene.ts`：世界与光照 RenderTexture、60Hz 移动、镜头、角色缓存与移动队列。
- `src/ui/game/villagers.ts`：原创点阵角色、正面行走与日常工作动画、统一头像。
- `src/ui/game/terrain.ts` / `paths.ts` / `lighting.ts`：地形碰撞、A* 寻路与独立光效着色器。
- `src/ui/PixelRoleplay.tsx` / `pixel.css`：游戏状态栏、标题画面、对话、日记与行动栏。
- `src/scenarios/roleplayTown.ts`：共同背景、六位角色的人设与私有目标、玩家身份。
- `src/agents/llm.ts`：局部观察下的角色决策、对玩家消息的优先回应。
- `src/server/playerView.ts`：玩家投影；`src/server/main.ts`：玩家接口、独立 WebSocket 和服务端调度。
- `src/engine/runtime.ts`：绑定玩家身份，和 NPC 使用同一行动注册表、校验和结算。

素材采用仓库原有的 Kenney Tiny Town / Tiny Dungeon（CC0），详见 `THIRD_PARTY_ASSETS.md`；没有使用《星露谷物语》的原始素材。

当前新版角色与头像已改为本项目原创的代码点阵，不再使用 Tiny Dungeon 人物。Phaser 为 MIT，随构建附带的许可证位于 `/licenses/Phaser-MIT.txt`。分层方式参考 [Soulforge](https://soulforge.glasden.top/)，没有复制其角色、地图、文案或着色器源码。

## 本次确认

生产构建和 TypeScript 检查通过。在实际浏览器中用 WASD 从广场走到咖啡店、触发区域切换、靠近阿栗按 E 打开对话，并通过已配置的 DeepSeek 收到针对玩家问题的真实回复。没有扩展测试矩阵，也没有把试玩一次描述成完整剧情验收。

居民空闲时会播放各自的工作动作，并在当前区域缓步活动；这些日常表现不额外调用模型或改变资源。人物不再切换头部朝向。路牌文字已改为与 Phaser 镜头每帧同步，详见 WORLD_RUNTIME_RENDERING.md。
