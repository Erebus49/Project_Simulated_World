# 新旧版本目录边界

新版代码现统一位于 `roleplay-town/`，它仍属于外层原有 Git 仓库，没有创建第二个嵌套仓库。

| 内容 | 新版位置 |
| --- | --- |
| 游戏界面、地图、人物与渲染 | `src/ui/` |
| HTTP、WebSocket、玩家投影 | `src/server/` |
| 规则、状态、结算与事件 | `src/engine/` |
| 模型、观察与演示策略 | `src/agents/` |
| 背景、人物和场景配置 | `src/scenarios/` |
| 模型本地配置 | `.env.runtime`，从原根目录原样迁入 |
| 静态素材与许可证 | `public/`，不再从旧前端读取 |
| 技术计划、说明、截图 | `docs/` |
| 本地记录、日志、备份 | `data/`，Git忽略 |
| 安装、构建与启动 | 本目录 `package.json`、锁文件、`start.bat` |

外层 `backend/`、`frontend/`、根目录 `start.bat` 继续属于旧版 Python 规则怪谈游戏。新版构建与运行不引用它们。共享的 Kenney 素材已经复制为新版自己持有的文件，旧版素材没有移除。

原根目录的新版 `src/`、npm清单、TypeScript/Vite配置、本地模型配置、依赖与构建目录已迁入本目录。旧运行记录保存于 `data/before-directory-move.json`；更早记录保存在 `data/runtime-before-phaser.json`，均可在调试台导入查看，含私有角色信息，不随代码提交。

新的默认端口为8011；正常启动方式见 [项目 README](../README.md)。本地模型地址、模型名与密钥的值没有在这次整理中更改。网络连接由用户自行恢复，本轮没有测试模型连通性。

## 整理后追加的玩法

地图从768×576扩大至960×720，原有位置保留，桥东新增可行走的河岸步道，南侧新增带花坛、长椅与花架的花园。水域仍阻挡行走，需通过桥面跨河。扩展部分仍属于广场的户外逻辑区域。

`routines.ts` 为每位居民定义四种活动，7–10秒左右换一项，人物手中道具、手势与活动标签同步切换。它们是本地日常表现，不会额外调用模型、自动增加收入或变更人物职业。实际行动仍交给 LLM 与世界规则。

头顶气泡包含路过时的日常短句与玩家已经收到的近期AI回复。日常短句使用场景台词，不能视为事实或模型调用结果；气泡不读取其他角色私聊。短句显示后有冷却，不在每次路过时反复弹出。
